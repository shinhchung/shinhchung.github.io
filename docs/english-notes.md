# English learning notes

The eight `content/notes/english-*.md` pages are complete copies of the English
practice notes in `shinhchung/Obsidian/HH-vault`, imported on 2026-09-25 from
commit `575817ec8d2a93254ec15e9108512cbd62badbeb`. Publication of the complete notes,
including their personal context, was approved by the owner.

Each page records its original path and revision in front matter and links to
that exact source. The source repository is private; reading its GitHub links
requires access, but the imported pages are public.

This is a content snapshot, not automatic synchronization. To update, review the
source changes, replace the body while preserving the page slug, and update the
source revision and link. Only English practice notes belong in this collection;
CCNA, Korean, job descriptions, and other vault content are outside this import.

Run `hugo --minify` and check `/notes/` plus the changed articles before publishing.
